# Publish NAYL now

1. Extract this ZIP and upload every file in this directory to the root of one GitHub repository. Do not upload the ZIP itself.
2. In Render, create **New > Blueprint**, connect the repository, and apply `render.yaml`.
3. Open `/admin`, create the first owner account, then use **Connect NAYL** to add and test the OpenAI, Google Places, Brave, and Resend credentials.

Public routes:

- `/` consumer
- `/business` provider
- `/admin` owner and operations

The NAYL marketplace, account system, request flow, quote submission, comparison, and booking run immediately. Third-party services become live after their owner-issued credentials are saved.
